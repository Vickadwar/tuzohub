=========================================================
SYSTEM VALIDATION & SMS RESPONSES
=========================================================
Once the session ends, the backend system processes the voucher and triggers an SMS response to the user.

1. SUCCESSFUL TOP-UP:
SMS: "Hongera! Voucher code [Code] is valid. Ksh [Amount] has been sent to your mobile wallet. Thank you for choosing Gamma Coatings. T&Cs apply: [Link]"

2. VOUCHER ALREADY USED:
SMS: "Pole, the voucher code [Code] has already been used. Please try another valid Gamma voucher."

3. INVALID VOUCHER:
SMS: "Pole, the voucher code [Code] is invalid or not found. Please check the number and dial *453*34# to try again."

4. SYSTEM PENDING/DELAY (If Float is delayed):
SMS: "Dear [Name], your voucher [Code] has been received and is pending processing. Your wallet will be topped up shortly once confirmed."
